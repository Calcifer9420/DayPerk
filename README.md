## I. Work tracking and time value

### 1. Make your workday add up

Start tracking when work begins, pause when you take a break. Keep the same day’s pay while spending part of the day taking it easy, and you’ve won some time back. Work longer for the same pay, and the deal goes the other way. **Today’s balance** puts a price on the difference

## VII. Build and license

### 1. Build it yourself

You can also download the [macOS release](https://github.com/Calcifer9420/DayPerk/releases/latest).

Requires macOS 14.5 or later and Xcode with Swift Testing

```bash
git clone https://github.com/Calcifer9420/DayPerk.git
cd DayPerk
xcodebuild -project DayPerk/DayPerk.xcodeproj -scheme DayPerk \
  -configuration Release -destination 'platform=macOS' \
  -derivedDataPath build.noindex CODE_SIGNING_ALLOWED=NO build
```

The output is `build.noindex/Build/Products/Release/DayPerk.app`. Copy it to Applications, open it, and click the menu-bar coffee cup
