## I. 工作计时与时间价值

### 1. 别光顾着上班 看看今天赚回了多少

工作时开计时，休息时停一下。同样拿一天工资，摸鱼的时间是你赚回来的，多搭的时间是你倒贴的。「今日价值差额」把这笔时间账折成金额，看看今天这班到底谁赚了

## VII. 构建与许可

### 1. 自己构建

也可以直接下载 [macOS 安装包](https://github.com/Calcifer9420/DayPerk/releases/latest)

需要 macOS 14.5 及以上，以及支持 Swift Testing 的 Xcode

```bash
git clone https://github.com/Calcifer9420/DayPerk.git
cd DayPerk
xcodebuild -project DayPerk/DayPerk.xcodeproj -scheme DayPerk \
  -configuration Release -destination 'platform=macOS' \
  -derivedDataPath build.noindex CODE_SIGNING_ALLOWED=NO build
```

产物是 `build.noindex/Build/Products/Release/DayPerk.app`。复制到“应用程序”后打开，点击菜单栏咖啡杯使用
